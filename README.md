# ethics-precheck

臨床研究申請書類のプレチェックを、Codexで安定した方針・手順・品質で実施するための運用リポジトリです。

このリポジトリは、研究資料そのものを保存する場所ではありません。研究ごとのPDF、Word、抽出テキスト、プレチェック結果はローカル作業用として扱い、GitHubにはアップロードしません。

## 目的

- 申請資料の不足、文書間不整合、倫理指針上の確認点、説明文書の分かりにくさを整理する。
- 倫理審査委員会の判断を代替せず、研究者が修正しやすい「修正対応依頼」を作成する。
- どの研究が来ても、同じ確認方針、同じ手順、安定した品質でプレチェックできるようにする。

## GitHubに保存するもの

- `AGENTS.md`
- `docs/`
- `examples/gold_reviews/README.md`
- `tools/` のうち汎用ツール
- `★倫理申請_修正対応依頼.docx`
- `.gitignore`
- `README.md`

## GitHubに保存しないもの

- `research-folder/`
- `tmp/`
- 研究ごとのPDF、Word、申請資料
- 研究ごとの抽出テキスト
- 研究ごとの `99_プレチェック出力/`
- 研究内容を埋め込んだ一回限りの生成スクリプト

## 基本運用

1. 新しい研究フォルダを `research-folder/` に置く。
2. Codexは `AGENTS.md`、`docs/review_quality_playbook.md`、`examples/gold_reviews/README.md` を読む。
3. 必要に応じてローカルのGold Exampleを参照する。
4. 研究資料を確認し、`99_プレチェック出力/` に結果を作成する。
5. 返却用Wordは `★倫理申請_修正対応依頼.docx` をコピーして作成し、テンプレートの表・枠を保持する。
6. プレチェック完了後、研究資料や研究フォルダはローカル運用に従って削除・入れ替えする。

## 注意

このリポジトリをprivateで運用してください。研究資料を誤ってコミットしないため、`.gitignore` で研究フォルダと一時ファイルを除外しています。
