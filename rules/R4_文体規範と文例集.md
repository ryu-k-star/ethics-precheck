# R4 文体規範と文例集

返却Wordは研究者が読んで対応する文書である。指摘の内容が正しくても、書き方が悪ければ対応されない。33版の実績から、実際に返却された文面の型を抽出する。

---

## 1 指摘文の構造

A欄の1項目は次の3要素で構成する。この順序を守る。

1. **現状**：どの資料のどこに何と書かれているか。項目番号・節番号・頁を明示する。
2. **問題**：何と一致しないか、何が読み取れないか。
3. **依頼**：何をすればよいか。動詞で終える。

```
本項目では〔現状の記載〕とされていますが、〔他資料の該当箇所〕では〔別の記載〕とされており一致していません。
〔判断すべきこと〕を確認し、〔対象資料〕の記載を統一してください。
```

依頼の動詞は「〜してください」「〜をご確認ください」を用いる。「〜が望ましい」「〜を検討されたい」は対応の要否が伝わらないため用いない。

## 2 使う語・使わない語

| 使わない | 使う |
|---|---|
| 齟齬がある、乖離している | 一致していません |
| 整合性を担保する | 整合させてください、統一してください |
| 記載が不十分 | 〔何が〕読み取れません、〔何が〕記載されていません |
| 適切に修正されたい | 〜に修正してください |
| ご対応方よろしくお願いします | ご対応をお願いします |
| 精査、深掘り、粒度、示唆、打ち手 | （用いない。具体的な動作で書く） |

- 略語は初出でフルスペルと日本語を示す。例：shear wave elastography（SWE、剪断波エラストグラフィ）。
- 敬称は「先生」を用いる。氏名は申請書の表記に合わせる。
- 判断が施設運用に依存する場合は断定せず、「〜をご確認ください」「〜に該当する場合は」の条件形で書き、同じ内容を05_人間確認事項にも記載する。

## 3 項目別の文例

### 3.0 先に `rules/R5` を見る

返却用テンプレート `★倫理申請_修正対応依頼.docx` には、20項目分の事務局定型文があらかじめ入っている。**該当する項目については、独自の文面を書き起こさず、`rules/R5` の定型文を基礎にして案件固有の値を差し替える。**

定型文がある項目：4、連絡担当者、12、13、16、19、23、24、25、26、27、29、30、31、39、43、44、46、47、48。

項目43・44には記載例まで用意されているため、研究者にそのまま提示できる。項目31は事務局内部向けの注記であり、そのまま転記してはならない。

以下の3.1以降は、定型文のない項目、または定型文だけでは足りない場合に用いる。

### 3.1 実績からの文例

実際に返却された文面から採る。〔〕は案件ごとに置き換える。

### 項目8 研究区分

> 本項目では「非介入研究（既存試料・情報のみを用いた後方視的研究など）」とされていますが、本研究は新たに〔アンケート／検査〕を実施して情報を取得する研究（項目18「新たに試料・情報を研究目的で取得して利用」）です。「非介入研究（前向き観察研究など）」への修正をご検討ください。

### 項目9 侵襲の有無

> 本項目は「軽微な侵襲あり」とされていますが、項目43・44は「侵襲を伴わないため該当しない」、項目45および説明文書〔節番号〕は「通常の診療を超える医療行為を伴わないため該当しない」とされており、申請内で侵襲の整理が一致していません。研究目的で追加する〔検査名〕の侵襲区分を確定し、項目43・44・45および説明文書〔節番号〕の記載を統一してください。

侵襲区分の判断に踏み込む場合は根拠を添える。

> アンケート調査は通常「侵襲なし」に区分されますが、精神的な負担があるようなアンケートの場合は、軽微な侵襲となるときもあります。

### 項目12 研究対象者

> 本項目の予定対象者数は〔A〕とされていますが、補完版4-4-1および説明文書〔節番号〕では「〔B〕」とされています。〔解析目標数と登録上限の区別／区分ごとの内訳〕を明確にしたうえで、申請システム・補完版・説明文書の記載を統一してください。

### 項目13 研究対象者の選定方針

> 選択基準に〔対象期間／年齢の下限〕が記載されていません。〔説明文書・オプトアウト文書〕では〔記載内容〕とされていますので、選択基準にも追記し、整合させてください。

除外基準の論理を指摘する場合。

> 選択基準を〔条件〕とした場合、〔条件〕に該当しない方はそもそも対象となりませんので、除外基準に記載する必要はありません。〔条件〕に該当する方の中で除外すべき方を除外基準に記載してください。

### 項目17 研究期間

> 申請システム及び説明文書〔節番号〕では研究終了日を〔日付〕としており、全体の研究できる期間として〔N〕か月ほどとなりますが、補完版4-3-1では「研究全体の実施期間を〔M〕か月」としており、仮に〔期間〕で〔目標数〕例目のエントリーができたとしても、ほとんど研究期間がありません。研究は少なくとも統計解析終了までが研究です。登録・追跡・解析を含む研究期間の意味を整理し、研究期間の整理をしてください。

この型は、期間差を指摘するだけでなく、なぜ足りないのかを登録・追跡・解析の順に示す点が要である。

### 項目19 研究で扱う試料・情報の種類

> 「匿名加工情報」にチェックされていますが、本研究は〔氏名・生年月日等を削除し符号化した個人情報として取り扱う運用／記名式アンケートで対応表を作成する運用〕であり、個人情報保護法上の「匿名加工情報」には該当しないと思われます。チェックを外してください。

> 「個人関連情報」にもチェックされていますが、個人関連情報は個人情報・仮名加工情報・匿名加工情報のいずれにも該当しない個人に関する情報を指します。本研究では自施設で対応表により本人と結び付けられる〔情報の種類〕を扱う計画ですので、該当性を再確認し、該当しない場合はチェックを外してください。

### 項目20 インフォームド・コンセントを受ける手続き等

> 「〔手続A〕」と「〔手続B〕」の両方が選択されていますが、添付資料として確認できるものは〔資料名〕です。〔手続A〕を行う対象・時期・記録方法がある場合は記載してください。〔手続B〕のみで実施する場合は、〔手続A〕のチェックを外すなど、申請項目と添付資料を整合させてください。

### 項目24 代諾者の選定

> 「代諾者を置かない」とされていますが、説明文書には「18歳未満の方は保護者の方の同意も必要」とあり、同意文書・同意撤回書に代諾者署名欄が設けられています。対象に18歳未満を含まれるなら、本項目は「代諾者を置く」としてください。もし18歳未満を含まない場合は説明文書の当該記載の削除と、同意文書等の代諾者署名欄を削除してください。

条件分岐を両方書き切るのがこの項目の型である。

### 項目25 個人情報等の取り扱い

> 本項目では個人情報等の管理責任者を「研究責任者」としていますが、説明文書〔節番号〕では「〔所属・職名・氏名〕」と記載されており一致しません。正しい管理責任者を確認し、申請システムと説明文書を統一してください。研究責任者以外が管理責任者となる場合は、項目4への記載の要否も併せてご確認ください。

### 項目27 試料・情報の保管場所

> 本研究は試料（血液・組織等の生体サンプル）を扱わないため（項目19で「試料」は未チェック）、試料の保管場所は「該当なし」と記載してください。

最頻出（7件）。定型で足りる。

### 項目35 同意撤回の保障

> 同意撤回の保障が「口頭」とされていますが、匿名アンケートのため回答送信後は個人を特定した撤回が困難と考えられます。回答送信前はいつでも回答を中断できるが、アンケート送信後は同意撤回ができない旨をご記載ください。

同意撤回書が添付され、説明文書に随時撤回できる旨と不利益を受けない旨が記載されている場合、同意撤回書の提出先・提出方法・撤回専用連絡先の追記は求めない。

### 項目47 将来の別研究に用いられる可能性

> 将来の別研究に用いる可能性を「あり」とされていますが、〔説明文書の節／同意文書〕では「将来の別研究に使用したり他の研究機関へ提供したりする予定はありません」と記載され、項目48も「可能性がない」とされています。将来利用を行わないのであれば本項目を「可能性がない」に修正し、項目26の継続保管のチェックも外してください。将来利用を行う場合は説明文書〔節番号〕の記載と項目26・47の内容を整合させてください。

## 4 B欄の書き方

添付書類ごとに小見出しを立て、資料単位でまとめる。1資料に複数の指摘がある場合は1つの段落に列挙する。A欄と関連する場合は「（A項〔番号〕と関連）」を付す。

```
・〔資料名〕：〔節番号〕の〔現状〕を〔期待〕に修正してください。〔次の指摘〕。
```

末尾は定型を維持する。

```
コメント対応後は、列挙した資料以外も含め、文書間の齟齬がないかご確認ください。

【ご協力お願いします】
スムーズな審査のため、変更履歴とコメントを削除してから再アップロードしてください。
```

## 5 指摘の量

33版の実績では、1版あたりの要対応は0〜13件、中央値は3件前後である。20件を超えると返却Wordが読み通せなくなる。

- 連動して解消する項目は代表項目に集約する。各項目に分ける場合は「項目〔N〕の整理に合わせ」と参照を入れ、独立した確認作業に見えないようにする。
- R2で「参考」の項目のみを理由に要対応を立てない。
- 同一の原因から派生する複数の資料の修正は、A欄に1件、B欄に資料ごとの修正指示、という形に分ける。

## 6 05_人間確認事項に回す条件

次のいずれかに当たる場合、04では確認依頼の形で提示し、同じ内容を05に記載する。

- 施設の運用方針に依存する（侵襲区分、研究実施機関の長、記載粒度）
- 資料からは事実が確定できない（氏名の誤記か別人か、意図的な別担当者か）
- 委員会の判断に属する（審査区分、除外基準の妥当性）

## 7 過剰指摘を防ぐ禁止例

次の不足だけを理由に、A欄・B欄の指摘を作らない。

- 将来利用のための継続保管について、通常の保管期間とは別の確定終期がない。
- 項目28に包括的な破棄方針があるが、媒体別の廃棄・消去手順がない。
- 説明文書に利用可能な電話番号等があるが、申請項目34のメールアドレスが転記されていない。
- 同意撤回書が添付され、説明文書に撤回可能性と不利益がない旨があるが、提出先・提出方法・撤回専用連絡先がない。

ただし、資料間の実質的な矛盾、相談窓口そのものの欠落、項目35で文書撤回を選択しているのに同意撤回書がない場合、撤回不能となる条件の説明不足は引き続き確認する。
