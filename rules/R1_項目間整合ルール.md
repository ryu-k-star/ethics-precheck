# R1 項目間整合ルール

倫理審査申請システム51項目と、研究実施計画書（補完版）・説明文書・オプトアウト文書・同意関連書式・アンケート・共同研究機関資料の間で、必ず突合する組み合わせを定める。

「実績」は `プレチェック完了` 配下33版の04_指摘事項書ドラフトで、当該ルールに該当する要対応が出た件数。件数が多いものほど優先して確認する。

適用方法：各ルールについて「条件に合致するか」を判定し、合致した場合に「期待」を満たすかを確認する。満たさない場合は「指摘先」の項目を要対応とする。判定できない場合は05_人間確認事項へ回し、04では確認依頼の形で提示する。

| 第2⑵ | 侵襲の定義。「侵襲のうち、研究対象者の身体又は精神に生じる傷害又は負担が小さいものを『軽微な侵襲』という」 | 軽微な侵襲は侵襲の下位区分 |
| 第6の1⑺ | 補償のための保険加入その他の措置 | 軽微な侵襲を**除く**、かつ通常の診療を超える医療行為を伴うもの |
| 第6の5⑵ | 重篤な有害事象発生時に必要な措置を講じる義務 | 軽微な侵襲を**含む** |
| 第7⑴⑳ | 研究計画書の記載事項：重篤な有害事象が発生した際の対応 | 軽微な侵襲を**含む** |
| 第7⑴㉑ | 研究計画書の記載事項：健康被害に対する補償の有無及びその内容 | 軽微な侵襲を**含む** |
| 第7⑴㉒ | 研究計画書の記載事項：研究実施後における医療の提供に関する対応 | 侵襲区分ではなく「通常の診療を超える医療行為を伴うか」で決まる |
| 第8の5⑳ | 説明事項：健康被害に対する補償の有無及びその内容 | 軽微な侵襲を**含む** |
| 第8の5㉒ | 説明事項：モニタリング・監査従事者等による試料・情報の閲覧 | 軽微な侵襲を**除く**、かつ介入を行うもの |
| 第9の1⑴イ(ア) | 未成年者の代諾の例外要件 | 侵襲を伴わない研究に限る（軽微な侵襲でも例外不可） |
