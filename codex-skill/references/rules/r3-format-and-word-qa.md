# R3 書式残骸・表記ルール

添付書類に残ったテンプレート文言、旧名称、表記ゆれを機械的に検出する。すべてB欄（添付書類の再アップロード）の指摘になる。

抽出テキストは全角・半角スペースと改行を除去した正規化文字列に対して検索すると、表のセル内改行やレイアウト由来の空白で取りこぼさない。

## T3 表記ゆれ・誤記の検出

| ID | 検査 | 方法 |
|---|---|---|
| T3-1 | 人名の表記ゆれ | 全資料から人名を抽出し、姓名の一致・異体字（惠／恵、廣／広）・同音異字（直樹／直輝、智広／知広）・全角半角スペースの有無を突合する |
| T3-2 | 電話番号の不一致 | 数字のみに正規化して全資料を突合する。1桁の相違も検出する。ハイフンの有無は表記統一の指摘とする |
| T3-3 | メールアドレスの誤記・不一致 | 同じ役割のメールアドレスが複数資料に記載されている場合だけ突合する。ある資料にメールアドレスがないこと自体は指摘しない |
| T3-4 | 全角数字と半角数字の混在 | `[０-９]` を検索し、同一文書内で半角数字と混在していれば指摘（例：`２029年`） |
| T3-5 | 見出し番号の全角半角混在 | 説明文書の見出し番号（`1５`、`4-３`等）を検出する |
| T3-6 | 見出し番号の飛び | 説明文書の見出し1〜21の連番を検査し、欠番があれば指摘する |
| T3-7 | 課題名の異表記 | 項目1の課題名を基準に、全資料の課題名を文字列比較する。語の増減、略称（英字trial名）の有無、括弧の重複を検出する |
| T3-8 | 製品名・略語の混在 | 同一概念に複数の表記がある場合（例：カタカナ表記の揺れ、英字略語と日本語名の併用）、初出定義と統一を指摘する |
| T3-9 | 対応する2部の文書間の表現差 | 研究者保管用と研究対象者保管用で、本文の語（「研究参加」と「研究協力」等）が異なる箇所を差分検出する |
| T3-10 | 日本語の誤り | `求められてない`→`求められていない` 等、い抜き・ら抜き・助詞の重複を検出する |

## T4 レイアウト・体裁

| ID | 検査 | 指摘 |
|---|---|---|
| T4-1 | 研究者一覧・研究組織の表がページをまたいでいる | 再アップロード時に読みやすい体裁か確認を依頼する |
| T4-2 | 同一文書内に同趣旨の文が重複している | 重複表現の整理を依頼する |
| T4-3 | 変更履歴・コメントが表示された状態でPDF化されている | 削除してから再アップロードを依頼する（返却Word末尾の定型文でも案内する） |

## 返却Word側の自己点検

作成した返却Wordに対して、提出前に必ず確認する。

| ID | 検査 |
|---|---|
| W-1 | 表は2つ。Table 1が52行×2列、Table 2が1行×1列 |
| W-2 | セクション数が雛形と同じ。A4縦、余白が雛形のまま |
| W-3 | コメント要素が0件（`word/comments.xml` が存在しない） |
| W-4 | 追跡変更要素が0件（`document.xml` に `<w:ins`／`<w:del` がない） |
| W-5 | 04のA欄要対応の全文とB欄の全文がWordに転記されている（文字列一致で確認） |
| W-6 | 04で対応不要とした項目のセルが空である |
| W-7 | PDFへ変換し、全頁の抽出テキストで文字切れ・欠落がない |
| W-8 | 雛形ファイル自体のハッシュが作業前後で一致する |
| W-9 | テンプレート内蔵の事務局定型文（`rules/R5` の20項目）が、要対応としていない項目に消し残っていない。特に項目31の内部注記「読んだら消してください！！」が残っていないこと |
| W-10 | 定型文を流用した項目で、案件固有の値が差し替えられている（項目12の「300」、項目4の「前回の申請では」等） |
| W-11 | 返却Wordが `99_プレチェック出力/` または `99_プレチェック出力_<識別名>/` に保存され、ファイル名が `★倫理申請_修正対応依頼_研究課題名_作成日4桁.docx` である。仮名・英語名のまま完成扱いにしない。研究課題名にWindows禁止文字がある場合は全角の対応文字へ置換する |

W-9・W-10は、テンプレートをコピーして使う運用に固有の危険である。テンプレートのA欄第2列には20項目分の定型文が入っているため、記入欄を一度すべて空にしてから要対応項目のみ記入する。消し残ると、指摘していない項目に指摘が載る。
