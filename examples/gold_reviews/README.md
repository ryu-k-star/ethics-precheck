## 使い方

新しいプレチェックを開始する前に、対象研究に近いGold Exampleを少なくとも1件確認する。

重点的に見るファイル：

- `04_指摘事項書ドラフト.md`
- `06_ファクトチェック結果.md`
- `★倫理申請_修正対応依頼_*.docx`

確認する観点：

- 重要論点の拾い方。
- A、B、Cへの振り分け。
- 研究者向け依頼文の粒度。
- 人間確認事項に回す判断。
- Wordテンプレートの枠・表の保持方法。

## 注意

Gold Exampleは丸写しするためのものではない。対象研究の資料に基づいて、同じ品質基準、同じ文体、同じ優先順位の付け方を再現するために参照する。
